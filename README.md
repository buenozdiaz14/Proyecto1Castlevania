============================================
 CASTLEVANIA - README PARA NUEVOS JUGADORES
============================================

¡Bienvenido a Castlevania! Este es un juego de acción
y plataformas inspirado en los clásicos de vampiros.

Tu objetivo: atravesar el castillo, conseguir el arma
estrella y derrotar al jefe final (Phantom Bat).

────────────────────────────────────────────
 CONTROLES
────────────────────────────────────────────
  A / D         → Moverse izquierda / derecha
  Espacio       → Saltar / Planear (sala del jefe)
  Shift izq.    → Agacharse
  E             → Atacar (usa el arma equipada)
  1             → Equipar látigo (ataque cuerpo a cuerpo)
  2             → Equipar estrella (disparo a distancia)
  P o F1        → Abrir menú de trucos (durante el juego)

────────────────────────────────────────────
 MECÁNICAS DEL JUEGO
────────────────────────────────────────────

- Al empezar, pasarás un breve tutorial con Drácula.
- Avanza hacia la derecha eliminando enemigos (zombis).
- Recoge el ítem estrella (Estrella) que aparece en el suelo
  para poder usarla (luego pulsa 2).
- El látigo golpea a corta distancia; la estrella lanza un
  proyectil que viaja lejos y daña enemigos a distancia.
  La estrella tiene un pequeño enfriamiento entre disparos.
- Los enemigos te persiguen. Si te tocan sin el Modo Dios,
  pierdes una vida y aparece la pantalla de Game Over.
- Al llegar al final del primer nivel, serás teletransportado
  a la sala del jefe final.

────────────────────────────────────────────
 MOVILIDAD EN LA SALA DEL JEFE
────────────────────────────────────────────

  Al entrar en la sala del jefe, adquieres una habilidad
  especial que te permite moverte por el escenario con
  ventaja:

  - PLANEO: Si caminas hacia el borde de una plataforma y
    te dejas caer (sin pulsar Espacio para saltar), tu
    descenso será muy lento, permitiéndote planear
    largas distancias mientras evitas el suelo.
  - SALTO ADICIONAL: Durante ese descenso suave, puedes
    pulsar Espacio para ejecutar un nuevo salto y
    alcanzar las plataformas superiores. Esta técnica
    no funciona si has iniciado el movimiento con un
    salto; solo se activa al dejarte caer desde una
    cornisa.

  ¡Utiliza este truco para explorar la sala y esquivar
  los ataques del jefe desde cualquier altura!

────────────────────────────────────────────
 ARMAS Y EQUIPO
────────────────────────────────────────────

  Látigo: ataque cuerpo a cuerpo (tecla E).
  Estrella: ataque a distancia. Cada disparo consume
            energía y tiene un enfriamiento de 1 segundo.
            El proyectil tiene un alcance limitado.

  Cambia entre armas con las teclas 1 y 2.
  En la parte inferior de la pantalla verás el icono
  del arma equipada.

────────────────────────────────────────────
 JEFE FINAL (PHANTOM BAT)
────────────────────────────────────────────

  - Aparece al entrar en la sala del jefe.
  - Tiene 3 estados: colgado, volando y descansando.
  - Mientras vuela, dispara bolas rojas hacia ti.
    ¡Esquívalas o muere!
  - Periódicamente baja al suelo para descansar:
    ese es el mejor momento para atacar.
  - Necesitas golpearlo 4 veces para derrotarlo.
    Tras cada golpe, es invulnerable durante 0.5 segundos.
  - Al derrotarlo, ¡ganas el juego!

────────────────────────────────────────────
 TRUCOS (MENÚ DE CHEATS)
────────────────────────────────────────────

  Durante el juego, pulsa P o F1 para abrir un menú
  con las siguientes opciones (usa las flechas y Enter
  o haz clic con el ratón):

    • God Mode: ON / OFF → te vuelve invulnerable.
    • Teleport to Boss Room → te lleva directamente
      a la sala del jefe final.

  Puedes cerrar el menú con P, F1 o ESC.
  También puedes hacer clic en el texto [CHEATS: F1]
  de la esquina superior derecha para abrirlo.

────────────────────────────────────────────
 NOTAS FINALES
────────────────────────────────────────────

  - No necesitas instalar nada; solo extrae el ZIP,
    mantén el ejecutable junto a la carpeta "resources"
    y ejecuta Game.exe.
  - El juego guarda las opciones de trucos activadas
    hasta que las desactives manualmente.
  - Si encuentras algún problema, asegúrate de que la
    carpeta "resources" esté en el mismo lugar que el
    ejecutable y contenga todos los archivos.

¡Disfruta la aventura y acaba con el murciélago!
